Custom id —

Pick from the dropdown, or type any model id yourself and it is used as-is.

A preset overrides the provider settings above for every chat — its own provider, model, key, temperature, reasoning effort and system prompt. Empty fields fall back to the settings here. Selecting a preset switches the AI immediately.

Shows the character's full image behind the messages (falls back to the square avatar). 0% hides it.

Brightness of the *action* text in messages. Spoken "quotes" always stay at full brightness.

A small tool-calling model reads every reply and swaps the character’s image to the best-matching pose.

Off = pick a pose once at the start of the chat and keep it.

Minimum confidence before the image is allowed to change. Higher = fewer, steadier swaps.

Requests are proxied through the local server, which stores this configuration (including the API key) in its SQLite database. Single-user setup — keys are not encrypted.
